# SparkAtlas

An independent, evidence-first DGX Spark field guide. Public Astro Starlight site with bundled Pagefind search; the private [builder](https://github.com/yuanlin2004/spark-atlas-builder) proposes reviewed Markdown changes through pull requests.

## Run locally

Node 22.19+ and npm are required.

```sh
npm ci
npm test
npm run build
npm run preview
```

Open http://localhost:4321/spark-atlas/. Pagefind is generated by Starlight during production builds; test search in preview, not the development server. `npm run dev` is for authoring.

## Publish

In repository Settings → Pages select **GitHub Actions** as the source. Push to main or dispatch Build and deploy Pages. Pull requests build and validate without deployment. The intended URL is https://yuanlin2004.github.io/spark-atlas/; a committed workflow alone does not establish a successful deployment. Inspect the Actions run and Pages environment.

## Editorial policy

The design prototype is served at `/spark-atlas/prototype/` in the local preview and the GitHub Pages build. It uses sample articles and fixture responses. The prototype is a snapshot of the design files in the builder repository under `docs/design/prototype/`.
